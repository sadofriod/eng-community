# English Speaking Coach - Scenario Seed (MVP)

Last Updated: 2026-04-08

## 1. Self Introduction

1. 30 秒自我介绍
2. 介绍你的当前职责
3. 介绍你最近完成的一个项目
4. 介绍你的优势与改进方向
5. 向新同事介绍你的工作方式

## 2. Meeting Update

6. 每周进展同步
7. 汇报一个延期风险
8. 说明当前阻塞与所需支持
9. 解释任务优先级调整原因
10. 会议结束前做总结

## 3. Suggestion and Disagreement

11. 提出改进建议
12. 礼貌表达不同意见
13. 请求澄清不明确需求
14. 在会议中拒绝不合理截止日期
15. 解释为什么要改变方案

## 4. Cross-team Collaboration

16. 向产品经理确认需求范围
17. 向设计师说明技术限制
18. 与测试同学对齐验收标准
19. 请求其他团队协助排查问题
20. 对外部依赖延迟进行沟通

## 5. Interview and Career

21. Why do you want this role?
22. Tell me about a challenge you solved.
23. Describe a conflict and how you handled it.
24. Explain one project with measurable impact.
25. Ask thoughtful questions to the interviewer.

## Scenario Metadata Template

每个场景建议带以下字段：

- id
- category
- title
- prompt
- targetPoints
- suggestedMinute

示例：

```json
{
  "id": "scn_meeting_01",
  "category": "meeting-update",
  "title": "每周进展同步",
  "prompt": "You are in a weekly standup. Share what you finished, what you are doing now, and any blocker.",
  "targetPoints": [
    "clear structure",
    "time reference",
    "specific blocker ask"
  ],
  "suggestedMinute": 12
}
```
